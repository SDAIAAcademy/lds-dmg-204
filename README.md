# تصنيف البيانات في التطبيق العملي

Data Classification in Practice

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-DMG-204 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يصنف المشاركون بيانات جهة افتراضية من البداية إلى النهاية: يحددون نطاق الأصول المهيكلة وغير المهيكلة، ويقدّرون أثر الإفصاح، ويربطون التقديرات بالمستويات، ويحددون ضوابط التعامل، ويسجلون في سجل التصنيف القرارات التي اعتمدها الملاك. ثم يقيسون عدد المرات التي يخطئ فيها مسار معالجة للوسم الآلي مقارنة بقراراتهم، ويضعون قواعد للمراجعة البشرية.

**الصيغة:** ورشة عمل: يوم ونصف مع مختبرات، ومهمة متابعة قصيرة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-dmg-204/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يطبق تقييمًا للأثر لاقتراح مستوى تصنيف لكل أصل، على 20 أصلًا اصطناعيًا من البيانات المهيكلة وغير المهيكلة | Applied | تقديرات ومستوى ومبرر تطابق المرجع في 16 أصلًا على الأقل |
| LO2 | يعدّ متطلبات التعامل لكل مستوى في التخزين والنقل والمشاركة والاحتفاظ والإتلاف، استنادًا إلى أنظمة الجهة وكتالوج للضوابط | Applied | مصفوفة تعامل فيها ضابط مسمًّى لكل مستوى ومرحلة |
| LO3 | يعدّ مدخلات سجل التصنيف مع اعتماد المالك والاستثناءات وتواريخ رفع التصنيف، استنادًا إلى قرارات المختبرات وحالتين متنازع عليهما | Applied | مدخلات مكتملة ومذكرة تصعيد لكل نزاع |
| LO4 | يقيّم مسار معالجة للتصنيف المدعوم آليًا ويحدد متى يجب أن يراجع شخص النتيجة، استنادًا إلى وسوم آلية لـ 200 عنصر اصطناعي | Performance | معدلات الإغفال والإنذار الكاذب لكل مستوى، وسياسة مراجعة تتضمن قواعد التوجيه |
